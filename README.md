# 👁️ Open Vision Lab

An open-source computer vision lab combining structured learning, hands-on projects, and reproducible experiments. This repository documents the journey from fundamental concepts to advanced systems with clean, modular, and scalable implementations, real-world applications, and continuous exploration of modern AI techniques.

## 📂 Repository Structure
- `lab/` → Experiments and prototypes
- `experemnt/` → Experimental setups and configurations
- `project/` → Organized projects with clear objectives
- `reserch/` → Research papers, findings, and notes
- `problem/` → Problem statements and challenges
- `data/` → Datasets for training and testing
